# PersonalWeb

Учебный персональный сайт в двух самостоятельных версиях. PHP-версия демонстрирует серверное MVC, маршрутизацию, валидацию форм, регистрацию, блог и тестирование пользователей. Vue-версия демонстрирует компоненты и клиентскую маршрутизацию.

## Vue 3

Требуются Node.js и npm.

```powershell
cd vue
npm ci
npm run serve
```

`npm run build` собирает статическую версию сайта.

## PHP MVC

Требуются PHP 8.2 с расширением PDO MySQL и локальная MySQL или MariaDB. Укажите параметры в переменных `DB_DSN`, `DB_USER` и `DB_PASSWORD`. DSN должен включать имя базы. Для начальной установки пользователь БД должен иметь право создать схему.

```powershell
cd php-mvc
php database/setup.php
php -S 127.0.0.1:8011 router.php
```

Откройте [локальный сайт](http://127.0.0.1:8011). Регистрация обычного пользователя доступна по адресу `/auth/register`. Фотографии галереи в этой копии заменены демонстрационными изображениями.
