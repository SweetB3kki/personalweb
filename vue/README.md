# web.finaly

Персональный сайт на `Vue 3`, полностью переоформленный в стилистике ретро-десктопа и оконного интерфейса DamnWear.

## Структура

- `src/views` — страницы сайта
- `src/components/layout` — общий shell и каркас приложения
- `src/components/ui` — переиспользуемые оконные и кнопочные компоненты
- `src/data` — контент и навигация
- `src/styles` — глобальная тема
- `public/branding` — логотип и знак бренда

## Команды

```bash
npm install
npm run serve
npm run build
npm run lint
```

## Что изменено

- убрано дублирование разметки между страницами;
- исправлен двойной `mount` приложения;
- навигация переведена на читаемые URL;
- общий визуальный стиль вынесен в глобальные токены и базовые UI-компоненты.
